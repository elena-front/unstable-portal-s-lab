# Лаборатория нестабильных порталов

Короткая стратегическая игра: за 10 минут нужно исследовать восемь миров и вернуть
как можно больше сотрудников. Порталы возникают случайно, теряют энергию и могут
схлопнуться. Оператор выбирает размер экспедиции, стабилизирует важные порталы и
организует возвращение команды.

## Запуск

Нужны Node.js 24+ и npm 11+.

```bash
npm ci
npm run dev
```

Vite выведет локальный адрес приложения. Откройте его в браузере. Перед первой и
каждой новой партией прочитайте краткие правила, выберите обычную игру или
проверочный сценарий и нажмите «Начать партию». Во время выбора таймер стоит.
После старта сценарий больше не показывается; история завершённых партий
сохраняется.

## Правила и формулы

- В начале партии доступны 12 сотрудников. Через активный стабильный или опасный
  портал можно отправить группу из 1–4 человек. В критичный портал отправка
  запрещена; через него разрешена подтверждённая аварийная эвакуация. В уже
  исследованный мир новая группа не отправляется.
- Энергия портала `E` находится в диапазоне 0–100. Рассеивание `D` и стабильность
  `S` — в диапазоне 0–1. Эффективное рассеивание `K = D × (1 − S_effective)`.
  Каждую секунду энергия меняется по формуле `E_next = max(0, E − K × Δt / 10)`.
- Оставшееся время `T = 10 × E / K`; риск `R = clamp(1 − T / T_initial, 0, 1)`.
  При `K = 0` время бесконечно, риск нулевой. При `E = 0` портал схлопывается.
  Риск ниже 50% считается стабильным, от 50% до 80% — опасным, от 80% — критичным.
- Переход одного сотрудника стоит `2 + 3D + 2(1 − S_effective)` единиц энергии.
  Исследование идёт со скоростью `√n` единиц в секунду для `n` сотрудников.
  Исследованный мир не возвращает людей автоматически.
- На партию есть три попытки стабилизации. Шанс успеха зависит от риска и
  наблюдателя: `clamp(0,90 − 0,65R + 0,15 × observer, 0,20, 0,80)`.
- Критичный портал в неисследованный мир можно закрыть при наличии другого
  надёжного маршрута. По истечении таймера миссия выполнена, если исследованы
  все миры. Очки — процент сотрудников, вернувшихся в лабораторию.
- Единственный стабильный маршрут в мир можно стабилизировать. Досрочное
  закрытие работающего портала сокращает ожидание следующего до пяти секунд.
  Схлопнувшийся портал остаётся в оперативном списке и занимает слот, пока его
  не закроют вручную.

Полные правила, включая резервный маршрут, ручное закрытие и крайние случаи,
описаны в [спецификации](docs/PRODUCT_SPEC.md). Числовой баланс хранится в
[`src/config/gameBalance.ts`](src/config/gameBalance.ts).

## Проверки и сборка

```bash
npm run typecheck
npm run test:run
npm run build
npm run preview
```

`preview` открывает собранную версию локально. Результаты автоматических и ручных
проверок находятся в [отчёте этапа 5](docs/TEST_RUN_STAGE5.md).

## Ограничения

Игра работает только в браузере. Текущая партия и история результатов хранятся
в LocalStorage этого браузера; синхронизации между устройствами и аккаунтов нет.
Когда вкладка неактивна, симуляция приостанавливается без догоняющего расчёта.
Баланс — стартовый и требует дальнейших игровых прогонов. Данные демонстрационные.
