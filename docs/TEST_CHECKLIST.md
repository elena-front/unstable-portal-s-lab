# Чеклист проверки

## Автоматические проверки

- [x] Тестовая `GameBalanceConfig` меняет длительность, лимиты и коэффициенты
  без изменения production-конфигурации или доменных функций.
- [x] Формула корректно классифицирует стабильный, опасный и критичный портал
  на границах 0%, 50%, 80% и 100%.
- [x] `E = 0` и `K = 0` обрабатываются без `NaN` и деления на ноль.
- [x] За одну секунду энергия уменьшается на `K_effective / 10` и не становится
  отрицательной.
- [x] Новые `D` и `S` появляются на 60-й секунде, но не раньше.
- [x] При начальном `K_effective = 0` риск равен 0%, `T_initial = null`, а первое
  конечное время фиксируется как `T_initial` без скачка риска.
- [x] Энергия влияет на риск только через оставшееся время жизни.
- [x] Портал получает количество сотрудников из связанного мира.
- [x] Нельзя создать 21-й незакрытый портал; `collapsed` входит в лимит, а
  `closed` — нет.
- [x] При лимите 20 появление ожидает; ручное закрытие создаёт портал на
  следующем тике.
- [x] Вручную закрывается портал только в `explored`-мир.
- [x] Последний маршрут к сотрудникам закрыть нельзя; при надёжном резерве
  закрытие требует подтверждения и разрешено.
- [x] Первый мир и интервалы появления выбираются внедрённой случайностью.
- [x] После двух известных миров директор выбирает случайный скрытый мир.
- [x] Критичный портал без сотрудников необратимо становится закрытым.
- [x] Портал с нулевой энергией становится схлопнувшимся.
- [x] Схлопнувшийся портал блокирует слот до ручного закрытия.
- [x] Закрытие `collapsed` доступно независимо от мира и сотрудников, удаляет
  портал из оперативного списка и сохраняет событие в журнале.
- [x] Важность учитывает сотрудников и все активные порталы в тот же мир.
- [x] Переход `N` сотрудников уменьшает энергию ровно на рассчитанную стоимость.
- [x] Группа, исчерпывающая энергию портала, не отправляется без надёжного
  резервного портала.
- [x] При надёжном резерве группа проходит, а использованный портал становится
  `collapsed`.
- [x] Опасный, слишком короткоживущий или энергетически недостаточный второй
  портал не считается надёжным резервом.
- [x] При возвращении группа достигает лаборатории до схлопывания исчерпанного
  портала; второй резерв не требуется.
- [x] Аварийный возврат через критичный портал требует подтверждения, возвращает
  группу по обычной цене и принудительно переводит портал в `collapsed`.
- [x] Отправка из лаборатории через критичный портал остаётся запрещённой.
- [x] Исследование группы идёт со скоростью `sqrt(N)` и не превышает 100%.
- [x] Четвёртая попытка стабилизации за цикл запрещена.
- [x] Неудачная стабилизация расходует попытку, но не меняет параметры портала.
- [x] Успешная стабилизация не уменьшает время жизни на одной временной отметке.
- [x] При максимальном бонусе стабилизация запрещена и попытка не расходуется.
- [x] Наблюдатель повышает вероятность опасного портала и снимается после
  допустимой попытки.
- [x] Наблюдателя нельзя отправить в критичный портал даже при выполнении всех
  остальных условий.
- [x] Назначение наблюдателя снимается, если опасный портал становится
  критичным до попытки стабилизации.
- [x] Успешные и отклонённые действия попадают в журнал.
- [x] Сводка пересчитывается после изменения портала.
- [x] В неактивной вкладке не меняются таймер, энергия, исследование и таймер
  появления портала; после возврата нет догоняющего пересчёта.
- [x] Истечение таймера завершает партию, блокирует действия и последующие тики,
  а результат сохраняется в историю ровно один раз.
- [x] В конце цикла сотрудники вне лаборатории считаются потерянными.
- [x] Полное исследование всех миров до истечения таймера не завершает партию.
- [x] Новая партия сбрасывает оперативное состояние, но сохраняет историю
  результатов и обновляет последний результат после следующего завершения.
- [x] Повреждённые текущая партия и история LocalStorage обрабатываются
  независимо и не ломают запуск.
