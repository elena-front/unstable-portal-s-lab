# Результат проверок этапа 5

Дата: 16 сентября 2026 года. Проверял AI в локальном Chrome Headless через
Chrome DevTools Protocol, без редактирования игровых данных в браузере.
Проверочные состояния загружались через интерфейс. Автоматические тесты
выполнялись Vitest. Ручной просмотр скриншотов был выполнен для стартового
экрана на 320 и 1440 px.

| Сценарий из чеклиста | Результат | Что проверено |
| --- | --- | --- |
| 1. Пустой список | Пройден | Новая партия показывает объяснение и кнопку демоданных; кнопка открывает порталы. |
| 2. Критический портал | Пройден | Видны статус, процент, время, энергия, коэффициенты, рекомендация и причина запрета отправки. |
| 3. Изменение во времени | Пройден | Ускорение меняет расчёт портала; карточка и сводка обновляются. Журнал получает события действий и терминальных переходов; обычное обновление коэффициентов отдельным событием не записывается. |
| 4. Экспедиция | Пройден | Первый портал появился после новой партии и открыл неисследованный мир. Прогноз для группы из 1 и 4 человек показал 2 и 8 энергии. Отправка без резерва заблокирована, с резервом разрешена; исследование достигло 100%, сотрудники вернулись. Аварийная эвакуация схлопнула критичный портал. |
| 5. Стабилизация | Пройден | Для опасного, критичного и опасного с наблюдателем показаны шансы 51%, 31% и 66%; доступны сценарии успеха и неудачи, счётчик попыток и объяснение запрета наблюдателя для критичного портала. |
| 6. Закрытие и схлопывание | Пройден | Критичный портал оставался открытым, пока в мире был сотрудник, и закрылся после возврата через другой маршрут и тика. Схлопнувшийся портал занимал слот до ручного закрытия. При лимите 20 ручное закрытие в исследованный мир освободило место ожидающему порталу. |
| 7. Завершение и сохранение | Пройден | Журнал пополнялся после действий; результат сохранился после перезагрузки. При переключении вкладки таймер оставался на 06:04, после возврата продолжился с 06:03 без догоняющего времени. Новая партия сохранила историю, отдельная очистка потребовала подтверждения. |

## Доступность и компоновка

- Chrome: 320 px — `scrollWidth = 320` в пустом состоянии, раскрытом блоке
  сценариев и карточке портала. При 1440 px `scrollWidth = 1425` с полосой
  прокрутки, горизонтального переполнения нет.
- Клавиатура: Tab достигает основной навигации и строки портала; Enter открыл
  AI Worklog, Space выбрал портал и отправил группу. Системный диалог аварийной
  эвакуации принял подтверждение; после исчезновения кнопки возврата фокус
  переместился на «Закрыть схлопнувшийся портал».
- По итогам проверки исправлены ширина списка сценариев на 320 px, потеря
  фокуса после эвакуации и флаг критической истории у сценария исследованного
  мира. Проверки выявили ошибки в нескольких временных браузерных скриптах;
  исправления скриптов не меняли продуктовый код.
